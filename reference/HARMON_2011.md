# Data: Relative decay reduction factors

Data: Relative decay reduction factors

## Usage

``` r
HARMON_2011
```

## Format

A data frame with 261 rows and 17 columns:

- Genus:

  Tree genus name.

- Species:

  Tree species name.

- Code:

  Original species code from Harmon et al. (2011).

- NFI_CODE:

  Adapted species code to match NFI naming.

- ...:

  Columns DC_1 through DC_5: relative decay reduction factors for each
  decay class.

## Source

Adapted from Harmon et al., 2011 Appendix D. Added Values:

- Populus trichoptera added. Same values as Populus balsamifera
