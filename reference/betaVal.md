# Internal Function: Beta Values

Internal Function: Beta Values

## Usage

``` r
betaVal(method, species, component)
```

## Arguments

- method:

  Dataframe within the package to retrive beta values from. Options are
  "LAMBERT_1", "LAMBERT_2", "UNG_1", "UNG_2".

- species:

  gets specifed from parent function. Will be an NFI code

- component:

  one of "WOOD", "BARK", "BRANCHES" or "FOLIAGE".

## Value

A list of 2 or 3 beta values

``` r
NA
#> [1] NA
```
