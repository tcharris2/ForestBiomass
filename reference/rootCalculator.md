# Internal Function: Root Biomass Calculator

Internal Function: Root Biomass Calculator

## Usage

``` r
rootCalculator(data, biomass, species, root_type, output)
```

## Arguments

- data:

  User specified dataframe.

- biomass:

  Column within data where pre-computed above-ground biomass (Mg/ha) is
  specified.

- species:

  Column within data where species is specified. NFI codes for species.

- root_type:

  One of "total", "fine", or "coarse".

- output:

  One of "biomass Mg/ha" or "carbon Mg/ha".

## Value

A numeric vector.
