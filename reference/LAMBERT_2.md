# Data: Coefficients for allometric equations for DBH and HEIGHT

Data: Coefficients for allometric equations for DBH and HEIGHT

## Usage

``` r
LAMBERT_2
```

## Format

A data frame with 432 rows and 4 columns:

- SPECIES:

  Species codes. Follows NFI naming conventions

- COMPONENT:

  Part of the tree

- BETA_NUM:

  Corrresponds to beta coefficents

- VALUES:

  Values

## Source

Values from Lambert et al., 2005 Canadian national tree aboveground
biomass equations
