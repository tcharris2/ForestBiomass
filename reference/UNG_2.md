# Data: Coefficients for allometric equations for DBH and HEIGHT

Data: Coefficients for allometric equations for DBH and HEIGHT

## Usage

``` r
UNG_2
```

## Format

A data frame with 204 rows and 4 columns:

- SPECIES:

  Species codes. Follows NFI naming conventions

- COMPONENT:

  Part of the tree

- BETA_NUM:

  Corrresponds to beta coefficents

- VALUES:

  Values

## Source

Values from Ung et al., 2008 Canadian national biomass equations: new
parameter estimates that include British Columbia data
