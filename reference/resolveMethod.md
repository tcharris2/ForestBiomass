# Internal: Resolve allometric method, equation function, and height for dispatch

Internal: Resolve allometric method, equation function, and height for
dispatch

## Usage

``` r
resolveMethod(eval, height)
```

## Arguments

- eval:

  The allometric equation method string.

- height:

  Column name for height, or NULL.

## Value

A list with func, method, and resolved height (NULL for DBH-only
equations).
