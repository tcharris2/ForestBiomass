## Datasets

Allometric equation coefficients and species lookup tables.

- [`sample_trees`](https://tcharris2.github.io/ForestBiomass/reference/sample_trees.md)
  : Sample tree measurements
- [`UNG_1`](https://tcharris2.github.io/ForestBiomass/reference/UNG_1.md)
  : Data: Coefficients for allometric equations for DBH
- [`UNG_2`](https://tcharris2.github.io/ForestBiomass/reference/UNG_2.md)
  : Data: Coefficients for allometric equations for DBH and HEIGHT
- [`LAMBERT_1`](https://tcharris2.github.io/ForestBiomass/reference/LAMBERT_1.md)
  : Data: Coefficients for allometric equations for DBH only
- [`LAMBERT_2`](https://tcharris2.github.io/ForestBiomass/reference/LAMBERT_2.md)
  : Data: Coefficients for allometric equations for DBH and HEIGHT
- [`JENKINS`](https://tcharris2.github.io/ForestBiomass/reference/JENKINS.md)
  : Data: Jenkins et al. (2003) total above-ground biomass equation
  coefficients
- [`JENKINS_GROUPS`](https://tcharris2.github.io/ForestBiomass/reference/JENKINS_GROUPS.md)
  : Data: NFI species code to Jenkins species group mapping
- [`JENKINS_RATIO`](https://tcharris2.github.io/ForestBiomass/reference/JENKINS_RATIO.md)
  : Data: Jenkins et al. (2003) component ratio equation coefficients
- [`SPECIES_CLASS`](https://tcharris2.github.io/ForestBiomass/reference/SPECIES_CLASS.md)
  : Data: NFI species softwood/hardwood classification
- [`LI_2003`](https://tcharris2.github.io/ForestBiomass/reference/LI_2003.md)
  : Data: Li et al. (2003) root biomass equation coefficients
- [`HARMON_2011`](https://tcharris2.github.io/ForestBiomass/reference/HARMON_2011.md)
  : Data: Relative decay reduction factors
