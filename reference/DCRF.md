# Internal function: Decay Class Reduction Factor (DCRF)

Internal function: Decay Class Reduction Factor (DCRF)

## Usage

``` r
DCRF(data, appearance, species, i)
```

## Arguments

- data:

  User dataframe.

- appearance:

  Column from user dataframe where tree appearance is specified.
  Appearance codes correspond to Field Manual for Describing Terrestrial
  Ecosystems 2nd edition.

- species:

  Column from user dataframe with species code. Species code must be in
  NFI format.

- i:

  Used for iterating.

## Value

A decay modifer (numeric) corresponding to species and decay class
